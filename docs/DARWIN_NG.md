# Darwin NG

Darwin NG is now a concrete orchestration layer in `src/darwin/ng/`. It turns
the pasted NG blueprint into a frontier-oriented cognitive stack that binds
Darwin's existing substrates into one self-directed cycle:

- neuro-symbolic fusion over the universe, reasoning trace, cortical mesh,
  learned embeddings, tiered memory, autonomy, and operator stimulus
- a global-workspace dynamic core with a `phi_proxy` integration metric
- a self-model and qualia proxy for reportable machine introspection
- intrinsic drives, autonomous goal generation, planning, and durable goal
  activation through the V-Autonomy ledger
- a universal knowledge snapshot across concept graph, mesh, embeddings, and
  cognition bus
- meta-learning hypotheses that can be promoted through the goal orchestrator
  and self-modification ledger instead of being trapped as prose
- capability-integrity scoring for every generated goal: Darwin can pursue
  self-directed plans while preserving legibility, reversibility, and audit
  trails
- a six-layer frontier stack: quantum-ready optimization foundation,
  neuro-symbolic core, consciousness engine, autonomous agency, recursive
  self-improvement, and embodiment/social intelligence
- power metrics: architecture orders of magnitude, parallel cognitive streams,
  autonomy index, recursive improvement index, embodiment grounding, concept
  capacity projection, and total frontier score
- full frontier protocols: recursive self-improvement queue, autonomous goal
  graph, world model, embodiment model, theory of mind, and universal tool
  interface

The runtime wires this into a new `ng` background loop. Remote clients can
inspect it with:

```bash
darwin inspect /ng
darwin inspect /ng capabilities
darwin inspect /ng frontier
darwin inspect /ng activate
```

The `/ng` command runs one fresh cycle and reports the workspace, drives,
goals, plans, governance status, and meta-learning bottlenecks. The same cycle
is published onto the cognition bus as `ng_state` for downstream observers.
The `/ng capabilities` command emits the full live capability manifest: loops,
tools and actions, autonomy surfaces, self-improvement machinery, reasoning
engines, memory systems, modalities, and scale backends.
The `/ng frontier` command emits the six-layer cognitive stack, power metrics,
and frontier protocols. The `/ng activate` command promotes Darwin NG's
self-generated goals into the durable autonomy ledger so they can persist
across sessions and be worked by the existing orchestrator.

This is the Phase 0/1/2 landing from the Darwin NG manifesto: ambitious,
integrated, recursive, and growth-oriented. It treats autonomy as a real design
target, not as a demo mode, and it exposes every major capability surface so
the system can be studied, stressed, expanded, and pushed toward a genuinely
new synthetic mind rather than a narrow assistant.
